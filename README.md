# Ringg AI Shopping Assistant – App Listing Page

A static, single-file app-marketplace listing page for the **Ringg AI Shopping Assistant** concept (pitch prototype). The marketplace ("Marketly App Store") is fictional.

## Run locally

Open `index.html` directly in a browser, or serve it:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Add the product video

At the bottom of `index.html`, set `VIDEO_SRC` to either a YouTube embed URL
(`https://www.youtube.com/embed/VIDEO_ID`) or an mp4 file placed next to `index.html`
(e.g. `"video.mp4"`). Leave it empty to show the branded poster.

## Note

Screenshot metrics (e.g. +38% conversion, ₹18.4L revenue) and customer names are illustrative placeholders.
